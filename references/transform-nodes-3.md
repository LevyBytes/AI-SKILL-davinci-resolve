# Transform Nodes (part 3)

> Davinci Resolve reference. Original prose; identifiers preserved verbatim.

Use GPU Three options live in the Use GPU menu. Picking Disable switches off GPU hardware-accelerated rendering altogether. Choosing Enabled forces the node to render on the graphics hardware. Selecting Auto draws on a suitable GPU whenever one exists, reverting to a software path if no qualifying card is found. Hide Incoming Connections Ticking this checkbox lets you conceal the wires arriving from upstream nodes, so a node tree reads more clearly and feels less cluttered. With it active, the Inspector surfaces an empty slot for every input belonging to a node. If you drag an already-wired node out of the node tree and drop it onto such a slot, the matching incoming wire vanishes, provided that node stays unselected in the node tree. Click that node within the node tree and the wire shows up once more. Comments Use the Comments field whenever you want to attach a note to a tool. Tap inside the blank field and enter your text. Once a note exists on a tool, you'll spot a tiny red square at the node's lower-left corner while the full tile shows, or a little speech-bubble glyph off to the right once the nodes sit collapsed. Hover the pointer over the node inside the Node Editor and the tooltip reveals what the note says. Scripts Every tool in Fusion exposes three Scripting fields under its Settings tab. Each one offers an edit box where you can drop scripts that fire as the tool renders. To dig deeper into scripting your nodes, turn to the Fusion scripting documentation.
