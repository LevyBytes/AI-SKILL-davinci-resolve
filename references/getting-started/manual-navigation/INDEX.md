# Manual navigation

Version: DaVinci Resolve 20.3 Reference Manual. Context: Manual navigation.

### Find a section in the PDF manual

<a id="source-navigation-guide"></a>

Open the [20.3 Reference Manual navigation guide](https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_20.3_Reference_Manual.pdf#page=12). Select a title or page number in a table of contents to jump to that section. Click the hyperlink tab along the right edge of a page to return to the main table of contents.

<a id="source-why-is-this-manual-so-big"></a>

The manual covers editing, compositing, audio mixing and color grading. Use your PDF reader's search to find a control or workflow, then read the surrounding explanation and conditions. Check the [version and scope guidance](../../reading-versioned-references.md) before applying a procedure to your installed release.

### Check for application updates

<a id="source-automatic-davinci-resolve-updates"></a>

Choose `DaVinci Resolve > Check For Updates` to check for new versions and download an available update. This menu is described in the [20.3 manual's getting-started section](https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_20.3_Reference_Manual.pdf#page=11).

### Read the Color page controls shown in the navigation example

The navigation guide illustrates its links using Color page chapter pages. For the actual controls, read the [Color page interface and layout](../../color/using-the-color-page/color-page-interface-and-default-layout-of-the-color-page.md). For primary and secondary monitor contents, resizing, the single ultra-wide monitor option and `Workspace > Dual Screen > On`, read the [Color page dual-monitor layout](../../color/using-the-color-page/curves-palette-and-colorslice-palette.md#dual-monitor-layout).
